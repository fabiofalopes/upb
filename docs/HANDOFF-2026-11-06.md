## What this session built (committed: f01a6aa, 649b715, a81a943)

New CLI capabilities (all self-tested on a scratch provider before touching
real config; all green):

- `upb keys` — key status: variable names and present/missing only, never
  values. `upb keys set VAR` prompts with hidden, paste-safe input (getpass),
  stores to secrets.env (0600) after timestamped backups, pushes the key the
  systemd router is keyed on, restarts universal-router.service, then prompts
  `upb verify --probe`. `upb keys del VAR` removes (backup kept).
- `upb enable|disable PROVIDER --reason "..."` — quarantine is now a
  first-class action with a recorded reason; disabled providers are ineligible
  routes. Config is YAML-validated before write.
- `upb history [--json]` — replays the local JSONL audit log (health sweeps
  from every status/verify run, key set/delete events, enable/disable with
  reasons). Secret values are never logged.
- Health history is now persistent: every `upb status` / `upb verify` run
  appends provider health states to the audit log. "What was up and when"
  survives across sessions and machines.
